## V2EX / 小红书

标题：Codex 额度花在哪了？我做了一个小侧栏工具

用 Codex 时，我想知道哪些会话消耗最多，又不想一直打开分析页面，所以做了 Codex Usage Meter。

一个小侧栏就能查看：
- 周余量、重置倒计时，以及重置次数和到期时间
- 各会话的输入／输出 token、缓存命中率和模型用量
- 最近七天每天用了多少 token，鼠标放到柱子上就能看明细

免费开源，支持 macOS 和 Windows。需要 Python 3.10+ 和 Node.js 24+，安装后通过 Codex Usage Meter 启动 Codex。它是非官方实验性集成，欢迎反馈兼容性问题。

下载：https://github.com/gnuser/codex-usage-meter/releases/latest

## Reddit

Title: I built a small Codex sidebar panel to see where my tokens go

I wanted to compare usage across chats without repeatedly opening analytics, so I built Codex Usage Meter. It shows per-chat input/output tokens, cache hit rate, model details, seven days of daily tokens, and account reset countdowns.

It's free and open source, for macOS and Windows. It requires Python 3.10+ and Node.js 24+, and you launch Codex through its installed launcher. This is an unofficial, experimental sidebar integration; client updates can affect it. The short demo uses labeled sample data and authorized AI-cloned narration.

Code and installation: https://github.com/gnuser/codex-usage-meter

I'd appreciate feedback on the installation experience and what usage information is most useful.
