# Codex Usage Meter 1.4.0

A compact usage panel in the Codex sidebar, with a 27-second guide.

- Weekly allowance, reset countdown, reset credits and their expiry.
- Active-chat tokens, input/output, cache hit rate and model breakdown.
- Seven days of daily account tokens, with usage on bar hover.
- Token counts stay before chat titles on one line; updated navigation placement.

## Install / update

Download **CodexUsageMeter.zip**, extract it, and run **Install.command** (macOS) or **Install.cmd** (Windows). Requires Python 3.10+ and Node.js 24+ (a compatible bundled Node can be reused on Mac).

Quit Codex normally, then open **Codex Usage Meter** from `~/Applications` on Mac or the Windows Desktop. Use this launcher after every full quit. To update, repeat these steps with the new ZIP.

This is an unofficial, experimental integration and a source installation package, not a standalone signed binary. It uses a local-only debugging endpoint; client updates may affect compatibility. Token totals are not subscription allowance percentages. Public reset forecasts are unconfirmed community information.
